# mind_flow 测试说明（非正式发布版）

这个包里是**可运行的程序**，用来验证「按住空格说话 → 出文字 → 点时间戳回听 → 保存出文件」这条主流程。
完整的安装/使用文档在 `README.md`；这里只讲怎么最快跑起来、要验证什么、出问题怎么给我反馈。

**离线包（文件名带 `-offline`）：约 320MB 的识别模型已经放在 `data/models/` 里了，
启动后不需要下载任何东西，断网也能用。** 只有不带 `-offline` 的包才需要首次联网下载模型。

## 1. 包里有什么

| 文件 | 说明 |
| --- | --- |
| `mind_flow.exe` / `mind_flow` | 主程序，双击（Windows）或 `./mind_flow`（Linux）启动 |
| `sherpa-onnx-c-api.dll`、`onnxruntime.dll`、`onnxruntime_providers_shared.dll`、`sherpa-onnx-cxx-api.dll` | Windows 版的识别库，**必须和 exe 放在同一目录** |
| `mind_flow-engine.exe` | 可选的 GPU（CUDA）引擎。现在**不用管它**，等要测 GPU 时再把它和 CUDA 的 DLL 一起放进 `data\runtime\cuda\` |
| `data/models/` | 识别 / 标点 / VAD 模型（离线包已内置；`来源与校验.txt` 里是 SHA-256 与出处） |
| `示例语音_0.wav` | 模型自带的示例中文语音，想快速试试识别效果可以播放它、同时按住空格录 |
| `README.md` | 完整文档（含 GPU 安装步骤、模型手动下载、FAQ） |
| `测试说明.md` | 本文件 |

Windows 版已经静态链接了 MSVC 运行库，**不需要装 VC++ Redistributable**；
Linux 版只依赖系统自带的 glibc / libstdc++。两边都不需要 Python / FFmpeg / Node。

## 2. 三步跑起来

1. **解压到一个有写权限的目录**（例如 `D:\mind_flow_test\`；不要放 C:\Program Files，
   那里写数据会被拦）。
2. **启动**：Windows 双击 `mind_flow.exe`（首次可能弹防火墙，选「允许」或「取消」都行，
   程序只听本机）；Linux 在终端里 `./mind_flow`。
3. **等引擎就绪**：浏览器会自动打开 `http://127.0.0.1:8730`。状态条从「正在装载模型」变成 `CPU`
   就可以开始录了（离线包一般 1–2 秒）。

> 如果状态条一直提示「还没准备好模型 / 需要下载」，说明你拿到的是**不带 `-offline` 的包**：
> 照 `README.md` 第 3.3 节手动放模型，或者找我要离线包。

## 3. 建议按这个顺序测

| # | 操作 | 期望结果 |
| --- | --- | --- |
| 1 | 按住空格 2 秒说一句中文，松开 | 顶部出现「正在录音…」→ 松开后先出灰色「识别中」，随后变成文字 |
| 2 | 马上再按住空格说第二句 | 第一段还在识别也不影响，第二段正常录，两句话时间戳依次往后接 |
| 3 | 点第 1 句前面的时间戳 | 播放器跳到该句位置开始播；再点第 2 句时间戳，能跳到更靠后 |
| 4 | 点一句文字改几个字，按 Enter | 文字立刻保存；关掉再打开页面，改后的文字还在 |
| 5 | 录到一半按 F5 刷新浏览器 | 已识别的句子仍在，继续按住空格能从原时间轴接着录 |
| 6 | 填个标题，点「结束并保存」 | `data/recordings/` 出现 4 个同名文件：`.wav`（能直接播放）、`.txt`、`.json`、`.srt` |
| 7 | 开两个标签页 | 只有第一个能录音，第二个提示「另一个标签页正在录音，本页只读」 |
| 8 | 在句子里点一下再按空格 | 只输入空格、不触发录音（避免打断打字） |

## 4. 想重点看/反馈什么

- **识别准不准**：哪类句子容易错（人名、术语、口音、数字、中英混说）？
- **时间戳对不对**：点某句跳过去，听起来是不是就是那句话的开头？
- **手感**：按住松开的响应、识别等待时间（状态条的「识别中 N」持续多久）能否接受？
- **界面**：有没有多余的东西、缺什么信息、字太小/太挤之类。
- **出错时的信息**：把界面上的提示原文、终端里的日志、以及 `data/` 目录结构发我。

## 5. 数据放在哪 / 怎么清干净

```
<解压目录>/data/
  config.json     # 端口、下载源、推理设备
  models/         # 模型（约 320MB）
  sessions/       # 正在录的会话（含音频与逐段文字）
  recordings/     # 保存好的 .wav/.txt/.json/.srt
```

删掉整个解压目录 = 卸载干净；只想清空录音就删 `data/recordings/`；
想恢复出厂设置就删 `data/`（下次启动会重新下模型）。

## 6. 已知的取舍（不是 bug）

- 按住空格只在**打开本程序的标签页里**生效，不是系统级全局热键（全局热键会和输入法空格选词打架）。
- 只能本机访问，局域网上的手机/别的电脑打不开（浏览器只在安全上下文里给麦克风权限）。
- 说话短于 0.3 秒会被当误触丢掉；编辑文字时空格是输入空格、不录音。
- 不支持导入已有音频文件、说话人分离、翻译。
- GPU 默认没启用：本包只带 CPU 引擎（实测约 20–30 倍实时，1 小时录音识别约 2–3 分钟）。
  要测 GPU 按 `README.md` 第 4 节装 NVIDIA 驱动 + CUDA + cuDNN，再放好 `mind_flow-engine`。
